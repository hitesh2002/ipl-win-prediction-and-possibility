# IPL Win Prediction and Winning Probability

## Overview

This project aims to develop a machine learning system for predicting the winning team in an Indian Premier League (IPL) match and estimating the winning probability of the participating teams.

The project uses historical IPL match data to train and evaluate machine learning classification models. The system will later be integrated with a Django REST API and a web application to provide predictions through a user-friendly interface.

## Objectives

- Predict the winning team of an IPL match using machine learning.
- Estimate the winning probability of the participating teams.
- Compare different classification algorithms.
- Evaluate model performance using appropriate evaluation metrics.
- Integrate the trained model with a Django REST API.
- Deploy the application on the cloud.
